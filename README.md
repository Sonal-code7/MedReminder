#  MedReminder

A simple and user-friendly medication reminder and tracking web application built with Python and Streamlit.

MedReminder helps users organize their medicines, keep track of their daily schedule, and monitor medication adherence through a clean dashboard.

# Live Demo

🔗 https://scan-stop-12.streamlit.app/

# Features

- 💊 Add and manage medicines
- 🕐 Set medication times
- 📅 View today's medication schedule
- ✅ Mark medicines as taken
- 📊 Track daily medication progress
- 🔥 Streak tracking
- 📈 Analytics dashboard
- 📜 Medication history
- 🎨 Clean and responsive health-tech interface

##  Technologies Used:
- Python – Application logic
- Streamlit – Web application framework
- HTML & CSS – UI customization and styling
- Streamlit Session State – Managing application data during a session
